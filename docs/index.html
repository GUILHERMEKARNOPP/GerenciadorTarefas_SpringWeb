Gerenciador de Tarefas Web

Protótipos de tela

Spring MVC · Thymeleaf · Spring Data JPA · PostgreSQL

Telas navegáveis com dados fictícios: os botões e links levam às telas relacionadas. A usuária de exemplo (Ana Souza) é administradora, por isso o menu também mostra a área Admin. Cada tela tem, no rodapé, uma nota com a rota prevista no Spring MVC e as regras que ela segue.
