Notas do protótipo
  • Rota: GET /tarefas?q=&status=&prioridade=&categoria=&ordem=&pagina=, 10 tarefas por página.
  • Lista só as tarefas do usuário logado. Abrir o id de uma tarefa de outra pessoa responde 404.
  • O botão envia POST /tarefas/{id}/concluir e muda a tarefa para o status marcado como “finaliza a tarefa”.
  • Atrasada: vencimento antes de hoje e status que não finaliza a tarefa.
